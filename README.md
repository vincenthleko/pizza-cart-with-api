# 🍕 Pizza Cart App (with API Integration)

A web application that simulates a pizza cart system where users can select pizzas, view their cart, and calculate totals — powered by a RESTful API backend. Ideal for learning full-stack development with practical use of Express.js and Alpine.js.

## 📌 Overview

This project allows users to:
- View available pizzas
- Add pizzas to their cart
- Remove pizzas from the cart
- View the cart total
- Checkout and clear the cart
- Work with dynamic price plans and discounts

The app communicates with a backend API that manages pizza data, pricing logic, and cart state.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: HTML, CSS, Alpine.js
- **Database**: SQLite
- **API Testing**: Postman / Browser
- **HTTP Client**: Axios (optional)
